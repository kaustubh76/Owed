# Merchant policy documents

These are the published policies that `packages/policy-library` transcribes. Every clause
in that library carries a `source` pointing here and a `quote` of the wording, so the
transcription can be checked rather than taken on trust.

**The merchants are invented.** Northwind Parcel, Meridian Rides, Calder & Co. and Alder
Home Services do not exist, and these documents were written for the demonstration.
Submission rules bar unauthorised third-party trademarks, and a demo that files claims
against a named real retailer invites a question it does not need to answer.

The point of shipping them is the shape of the provenance chain, not the fiction: a real
deployment replaces these files with real published terms and the library with their
transcription, and nothing else changes.
